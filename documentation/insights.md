# Dashboard Insights

This document summarizes the analytical insights derived from
the Social Media Performance Dashboard.

The analysis is organized into three perspectives:

1. Executive performance
2. Platform performance
3. Content performance

---

## 1. Executive Performance

### Overall Performance

The Executive Overview monitors the following key performance
indicators:

- Total Views
- Total Engagement
- CTR
- Engagement Rate
- Total Posts
- Month-over-Month Growth

These KPIs provide a high-level view of social media performance
and allow changes in performance to be monitored over time.

### Time Trend

The monthly performance trend is used to identify changes in
views and engagement over time.

The dashboard allows the trend to be evaluated under different:

- Years
- Platforms
- Regions
- Content Types

This makes it possible to isolate performance patterns within
specific segments rather than relying only on aggregate results.

---

## 2. Platform Performance

The Platform Performance page compares social media platforms
using several efficiency metrics.

### Key Metrics

The analysis includes:

- Average Views per Post
- Average Engagement per Post
- CTR
- Engagement Rate
- Platform Efficiency

### Platform Efficiency

The `Platform Efficiency` measure is used to identify the
platform that performs most efficiently under the selected
filter context.

The dashboard also provides a `Most Efficient Platform` KPI
to summarize this comparison.

### Platform Comparison

The platform analysis compares reach and engagement rather than
relying on total views alone.

This distinction is important because a platform with high total
views may not necessarily generate the highest views or
engagement per post.

### CTR and Engagement

The scatter visualization allows CTR and Engagement Rate to be
examined simultaneously with Total Views.

This provides a multidimensional comparison of platform
performance.

---

## 3. Content Performance

The Content Performance page evaluates the effectiveness of
different content categories.

### Key Metrics

The analysis includes:

- Most Efficient Content
- Top Content Share
- Content Efficiency
- Average Views per Post
- Average Engagement per Post
- Total Posts
- Total Views

### Content Efficiency

The `Content Efficiency` measure is used to compare the relative
performance of content categories.

The `Most Efficient Content` KPI identifies the leading content
category under the current filter context.

### Content Contribution

`Top Content Share` measures the contribution of the leading
content category to the selected performance metric.

This helps distinguish between:

- Content that generates high absolute volume
- Content that performs efficiently relative to its number of posts

### Content and Platform Interaction

The dashboard evaluates content performance across platforms.

This allows the same content category to be compared under
different platform contexts.
